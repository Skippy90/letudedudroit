# Le Code pénal en bonhommes — plan de la série

Idée : illustrer le Code pénal article par article, avec les bonhommes, les objets et les décors de la charte, un thème à
la fois, en suivant la structure du code sur Fedlex (titres et chapitres, état au 1er novembre 2026). Chaque article :
une scène d'environ dix secondes, le bloc « Art. N CP », au plus douze mots à l'écran, fidèles au texte de Fedlex.

Statut : essais muets (sans voix), sans audit. Avant toute publication : script avec narration, audit des sources,
relecture, comme pour les autres vidéos. Les infractions graves (vie, intégrité sexuelle, génocide) restent abstraites :
on ne montre jamais l'acte.

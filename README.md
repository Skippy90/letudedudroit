# L'étude du droit

Chaîne YouTube pédagogique en accès libre sur le droit suisse romand. Chaque vidéo explique une notion, à partir d'un cas concret, avec les articles de loi cités à l'écran et vérifiés sur Fedlex.

Ce dépôt contient tout ce qui sert à produire les vidéos : les scripts, les tableaux d'audit des articles cités, les textes pour la narration, les projets d'animation et le curriculum. Tout est réutilisable par les enseignants, les étudiants et quiconque veut corriger, traduire ou prolonger le travail.

## Organisation

- `curriculum/` — les notions par matière, avec leurs prérequis et leur statut
- `scripts/` — un dossier par vidéo : `script.md`, `audit.md`, `tts.txt`, `visuals.md`
- `docs/` — la charte visuelle, le script de référence et le modèle d'audit
- `voice/` — la narration
- `render/` — les projets Manim (schémas) et Remotion (habillage, shorts)
- `out/` — les vidéos rendues

## Contribuer

Les corrections juridiques sont les contributions les plus précieuses. Ouvrez une issue en citant l'article et la version Fedlex concernés, ou proposez directement une pull request sur le script.

La méthode n'est pas dans la loi (consid. 4.1) : c'est une règle de jurisprudence. Aucun arrêt ultérieur n'a été ouvert ; le script cite seulement l'ATF 150 III 305 (vidéo 20), qui renvoie à cet arrêt pour le plafond (consid. 5.6).
- Exemple chiffré des lignes 22 à 31 : **fictif et simplifié**, inventé pour la vidéo, annoncé comme tel à l'oral (ligne 22) et à l'écran (lignes 22 et 31). Prénoms fictifs épicènes (Alix, Camille). Calculs : 8000 + 1000 = 9000 ; 9000 − (3500 + 3500) = 2000 ; 2000 / 2 = 1000 ; 3500 + 1000 = 4500 ; 4500 − 1000 = 3500. Plafond : 3500 + 1500 = 5000 (la part de 1500 pendant la vie commune est posée, pas calculée). Après le nouvel emploi : 8000 + 3000 − 7000 = 4000 ; 4000 / 2 = 2000 ; 3500 + 2000 = 5500 > 5000 ; 5000 − 3000 = 2000. Simplifications : pas d'enfants, pas d'impôts détaillés, pas d'entretien de prévoyance (Vorsorgeunterhalt), pas d'épargne. À dire dans la description. Point d'attention : la ligne 31 parle des enfants alors que l'exemple n'en a pas ; c'est une remarque générale (consid. 4.4).
- Droit cantonal : aucun. La procédure s'est déroulée en Argovie (Bezirksgericht Baden, Obergericht des Kantons Aargau), mais seul le droit fédéral est en cause.
- Droit d'auteur : les décisions des autorités ne sont pas protégées (art. 5 al. 1 let. c LDA, RS 231.1). Parties désignées comme dans l'arrêt (A., B.) ; les enfants (C., D.) ne sont pas nommés.

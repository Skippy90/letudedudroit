Réponse à la question finale :
C'est une erreur sur l'illicéité, car Sam sait que le portefeuille est à autrui ; il se trompe seulement sur son droit de le garder (article 21 du Code pénal). Sans autres précisions, on ne peut pas affirmer avec certitude si cette erreur était évitable. Il faudrait savoir ce que Sam savait, ou pouvait savoir, au moment d'agir. Par exemple : avait-il au moins un vague sentiment d'agir de manière illicite ? Un tel sentiment peut exclure l'erreur (ATF 104 IV 217, consid. 2) ; c'est un critère à vérifier dans les faits, pas une présomption. Si l'erreur était inévitable, Sam n'agit pas de manière coupable ; si elle était évitable, le juge atténue la peine. Garder une chose trouvée peut relever de l'appropriation illégitime (article 137 du Code pénal) ; lorsque l'auteur a trouvé la chose, l'infraction n'est poursuivie que sur plainte.

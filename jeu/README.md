# Pris dans le Code

Jeu pédagogique de la chaîne « L'étude du droit ». Un étudiant ou une étudiante en droit est aspiré par un vieux Code pénal et se retrouve dans des affaires. Pour sortir de chaque cas, il faut appliquer le droit correctement : chaque bonne réponse ouvre un verrou de la porte de sortie, chaque erreur déchire une page, et à trois pages déchirées le cas se referme et recommence.

- Six cas, un par vidéo de droit pénal général (vidéos 1 à 6), puis une dernière page qui reprend les questions de fin des vidéos.
- Points d'expérience : 20 XP par verrou ouvert du premier coup, 10 au deuxième essai, divisés par deux si l'on consulte le Code ; 30 XP de bonus pour un cas résolu sans page déchirée. Un cas déjà résolu peut être rejoué pour s'entraîner, sans XP.
- Grades : Première année (0), Deuxième année (150), Master (350), Stage d'avocat (550), Brevet d'avocat (800).
- La progression reste dans le navigateur du joueur (stockage local).

Un seul fichier, `index.html`, sans dépendance hormis les polices Google (Inter, IBM Plex Mono). Charte visuelle des vidéos : fond noir, silhouettes sans visage, décors au trait, ambre, vert pour ce qui est franchi, rouge réservé au dommage.

Contenu juridique : uniquement des règles et des réponses déjà écrites et vérifiées dans les scripts des vidéos 1 à 6. Voir `audit.md`.

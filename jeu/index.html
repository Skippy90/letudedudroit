Pris dans le Code

Tout le monde est parti. Un vieux Code pénal annoté traîne sur ta table. Tu l'ouvres : les articles s'allument en ambre, la page tourne toute seule et t'aspire. Tu atterris dans une affaire réelle, et tu n'en ressortiras qu'en appliquant le droit.

Dans chaque cas, explore le décor, parle aux personnes, ramasse les indices et les pages du Code, puis porte-les là où le droit les attend. Chaque bonne pièce ouvre un verrou de la sortie. Chaque erreur déchire une page, et les bords du cas se replient sur toi comme du papier. Trois pages déchirées, ou le temps écoulé : le cas se referme et recommence.
